# Computational-Theory-Assessment

This repository contains my submission for the Computational Theory module.
The project is written in a single Jupyter notebook, in Python.
Everything needed to run the notebook is included in this repository.

## Quick Look

- You can click on [problems.ipynb] in this repository and GitHub will display it in static format.
- You can view and run the notebook in [Google Colab]().
- You can view the notebook using [nbviewer]() too.

## Running the Notebook

In order to run `problems.ipynb` you can follow these steps:

1. Clone the repository using [git](https://git-scm.com/).
2. Ensure you have [Python](https://www.python.org/) installed. An easy way to get Python is to use [uv](https://docs.astral.sh/uv/) or [Anaconda](https://www.anaconda.com/download).

## Dependencies

The notebook depends on the [numpy](https://numpy.org/install/) package, the [matplotlib](https://matplotlib.org/stable/install/index.html) package.

## About the Notebook

The notebook focuses on the foundational concepts of computational theory and complexity. The goal for me, as a student, is to study formal models of computation, solvability, and computational resource requirements by identifying difficult computational problems in everyday computing; defining the common models of computation; designing computer programs using a variety of computational paradigms and analysing the complexity of an algorithm. This assessment is worth 100% marks of the module.
